# 可信传输ioctl审查与T1测试预算修正

这是公开脱敏汇总，不是原始测试报告。包含机器身份、运行路径和完整进程/容器信息的原件已单独保留，本次公开工作树不再包含这些原始记录；本文不能替代对原始记录的独立复算。历史失败、启动受阻和未完成的验收不会因整理而改为通过。

普通用户复现表明旧可信传输过滤器允许ioctl修改自有文件元数据，包括请求号高32位别名；该结果证明防御纵深缺陷，不等同于目标进程逃逸。修复为可信代理拒绝全部ioctl，目标策略另有契约。

[a505完整验证](final/README.md)保留Docker99 PASS及VM三轮失败；[806b预算修正验证](final-budget/README.md)为两环境各99 PASS。T1只将三个公网正例调整为curl30秒/CLI40秒/harness60秒，零自动重试；生产C、负例与受控网络时限不变。这是功能预算修正，不承诺公网10秒SLA，也不确定所有旧超时的原因。
