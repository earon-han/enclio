# 有限worker槽位同步诊断

这是公开脱敏汇总，不是原始测试报告。包含机器身份、运行路径和完整进程/容器信息的原件已单独保留，本次公开工作树不再包含这些原始记录；本文不能替代对原始记录的独立复算。历史失败、启动受阻和未完成的验收不会因整理而改为通过。

恰好三项有界对照各执行一次：旧行为基线PASS；旧行为加测试专用30毫秒worker退出延迟FAIL；同一注入二进制加同步屏障PASS。生产32-worker、10秒请求头期限及额外连接1秒接收断言均未放宽，没有断言重试。

旧测试可能在前一worker尚未回收时填充连接，造成槽位计数与实际存活连接不一致。同步版本先等回收，再逐连接确认SOCKS5 NOAUTH、存活连接及真实子进程，额外连接拒绝后进行一次恢复检查。

该实验只证明显式调度注入下的机制，不证明历史第408轮的完整时序或唯一原因，也不构成24小时验收。
